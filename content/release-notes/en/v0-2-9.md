This release focuses on two things: letting knowledge bases handle richer content, and giving administrators a clear view of how the platform is running.

## Multimodal knowledge bases

Knowledge bases now support multimodal assets, so images and other media can live alongside text. Images uploaded in chat can also be passed to the model as media references.

Document chunking gained **failed-chunk retry** and **bulk actions**: when one chunk fails to process, retry it instead of re-uploading the whole document. Prompt generation also draws on richer context.

## Admin observability and app management

The admin console now has an observability dashboard that brings platform health into a single page.

![Team management](https://rustfs-endpoint.yhnotes.com/content/team-management.png)

- New **app management** lets admins view and manage apps in one place
- Superadmins can now **transfer team ownership**
- Audit log UX is improved, with skill actions fully mapped

## Chat and agent experience

- Added text-to-speech
- Tuned the streaming timeout strategy for AI conversations
- Fixed collapsible sections freezing in production, thought-chain scroll flicker, and agent message version-branch context
- Fixed agent chat flicker and the agent orchestration layout on large screens

## Migration and integration

- **Import and export** Clouisle packages
- Added an API key shortcut for embed scenarios
