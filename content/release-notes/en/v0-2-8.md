v0.2.8 is a small but important fix.

## The problem

In containerized Docker production builds, system log routes were unintentionally excluded from the build output, leaving the related log pages unavailable.

## The fix

The build no longer excludes those routes. Teams running the standard Docker image can once again open audit and workflow execution logs straight from the UI.
