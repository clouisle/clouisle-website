v0.2.4 focuses on engineering guardrails and interaction details, and closes a few security and stability gaps.

## Release guardrails

Release tags must now point at `main`, preventing accidental releases from other branches.

## Skill imports

Git is pre-installed in the base image so third-party skills import smoothly.

## UI consistency

Unified the delete confirmation dialogs across the platform and fixed several protected-route and auth UI issues.

## Security and stability

- Fixed stack trace exposure in chat streaming endpoints
- Fixed a logs page 404 and an `UnboundLocalError` in chat streaming
