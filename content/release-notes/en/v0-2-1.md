v0.2.1 gives agents a memory, and teaches them to check in with you at the right moment.

## User memory system

Agents can carry user preferences, project conventions, and working context across conversations, so you do not have to re-introduce yourself every time.

## Agent input requests

During complex runs, an agent can pause at a key decision point and ask you for structured input before continuing, making human and agent genuine partners.

## Multi-architecture images

Improved the multi-architecture Docker image build pipeline.
