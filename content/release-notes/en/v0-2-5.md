v0.2.5 ships two production-focused improvements.

## Backend packaged as bytecode

The backend in Docker images is now packaged as precompiled Python bytecode. Containers start faster, with added code protection.

## Workflow log routing fix

Fixed a routing edge case for the frontend API in Docker deployments. Workflow execution logs stream reliably in real time, and call chains can be traced end to end.
