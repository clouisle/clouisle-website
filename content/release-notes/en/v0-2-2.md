v0.2.2 widens the choice of reasoning models and keeps docs and code in step.

## DeepSeek model support

Agentic Workflows now support DeepSeek models as a provider, bringing efficient reasoning to your workflows.

![Admin: creating a model](https://rustfs-endpoint.yhnotes.com/content/admin-model-create-dialog.png)

## Automated docs checks

Continuous integration now verifies documentation consistency: the ports, hostnames, and environment variables listed in deployment docs must match the source. The check also caught and fixed a `POSTGRES_HOST` / `POSTGRES_SERVER` mismatch in the docs.
