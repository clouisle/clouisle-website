v0.2.5 带来两处面向生产环境的改进。

## 后端打包为字节码

Docker 镜像中的后端服务现在会被打包为预编译的 Python 字节码，加快容器启动速度，同时增强了代码保护。

## 工作流日志路由修复

修复了 Docker 部署中前端 API 的路由边界问题。工作流执行日志可以稳定地实时查看，调用链路也能被完整追踪。
