# Dia Browser Recreation

This project is a local learning recreation of `https://www.diabrowser.com/`.

- Mode: visual and interaction recreation of the public home page.
- Source material: publicly delivered page copy, public imagery, and public Mux playback streams observed in the browser on 2026-08-26.
- Scope: hero, use-case selector, feature media, privacy demos, mobile menu, video dialog, CTA, and footer.
- License: the source site did not provide an open-source license during review. Treat this project and copied brand assets as local learning material only; do not publish or deploy it without permission from The Browser Company.

Run with `npm run dev`, then visit `http://localhost:3000`.
